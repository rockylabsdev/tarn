# Planning history

These documents show how Tarn was planned. They are kept as history, not as a current spec: the code and `GLOSSARY.md` are the truth.
`brief.md` and `brief-v2.md` are the starting briefs for v1 and v2. They name CleanShot X, the Mac tool that inspired Tarn.
`spec-v1.md`, `spec-v2.md` and `spec-public-v1.md` are the specs that came out of them, edited for an outside reader.
Issue numbers, tracker links and the throwaway research branches from the original planning have been left out.
New work is planned in public, on this repository's issues.
