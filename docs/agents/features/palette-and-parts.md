# Palette, shared QML parts and popovers

Read when working on a QML surface's colors, fonts, icons or shared parts (`Capsule`, `IconBtn`, `Tip`), or an Editor popover.

- `tarn::Palette` (`src/core/palette`, a daemon service) exposes the colors as properties and re-reads the file the `palette_file` Setting names (flat JSON, Material 3 names to `"#rrggbb"`; a rename over it is seen) when it changes. The `accent_color` Setting wins for the accent, then the file's `accent`, then `primary`; `on_accent` wins over `on_primary`. Tests write the file anywhere in the scratch folder and a `palette_file = "…"` line in `env.scratch() + "/config/tarn/config.toml"`, then assert on `service<Palette>().accent()` etc. (`QTRY_` after a live edit; `env.restartDaemon()` for the start state). `fromFile()` is true while a readable file is in use.
- `tarn::WatchedFile` (`src/core/settings`) is the one way to follow a file another tool writes: it watches the folders above the file so a rename over it is seen, and re-adds the watch after each read. `Palette` and `Wallpapers` use it; a new watched Setting reuses it, not a second watcher.
- `tarn::Wallpapers` (`src/core/wallpaper`) offers the current wallpaper from the first line of the file the `wallpaper_file` Setting names, then the images in `wallpaper_folder`. Tests (`tests/backgrounds`) write the file and a `wallpaper_file = "…"` line in the config, call `env.restartDaemon()` for the start state, then `QTRY_` on `current()` and the `changed` signal after a live edit or a rename over the file.
- Palette swatches show only while `theme.fromFile` is true: the color popover's "Palette" label and row (`popoverPaletteLabel`, `popoverPaletteSwatches`) and the Frame panel's swatches and gradients (`paletteSwatches`, `paletteGradients`). With none they are hidden, and the popover's Column leaves no gap. A Frame already saved with a Palette gradient keeps its stops and still opens. UI tests write a `palette_file` Setting and `QTRY_VERIFY` on `fromFile()`.
- QML reaches it as the `theme` context property (`theme.accent`, `theme.control`, ...), installed by `installTheme()` (`src/ui/theme.h`), which also loads the bundled Geist fonts and provides `icons.svg(name)`. Style values (radii, sizes) are the `Style` singleton. Parts: `Capsule`, `IconBtn`, `Sep`, `Icon`, `Tip`. A new surface calls `installTheme(view.rootContext(), palette)`; icons are `src/ui/assets/icons/<name>.svg`.
- **Popovers:** an Editor popover is a `Popover` (`Popover.qml`: look, padding, the close policy that lets its control's click `toggle()` it) declared inside the control that opens it. While open it is listed in the `Popovers` singleton, and the Editor's Esc closes the newest one under its window (`Popovers.closeNewestIn(root)`), so a new one needs nothing in `Editor.qml`. Tests reach a popover by `objectName` with `findChild<QObject *>` (a `Popup` is not a `QQuickItem`).
- QML `XMLHttpRequest` cannot read Qt resources: never load assets from QML that way.
